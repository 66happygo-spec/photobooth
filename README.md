# 外埔長青學院結業典禮拍貼機

專為 iPad / 平板觸控螢幕打造的純前端拍貼機 Web 應用，適合畢業典禮、銀髮樂齡結業式活動使用。

## 🎯 核心功能
- **相機預覽與鏡像翻轉**：如照鏡子般直覺。
- **倒數計時拍照**：大字體倒數（預設 3 秒或 5 秒），自動捕捉清晰相片。
- **3 款專屬主題相框選擇**：
  1. 溫馨花草木質框（牽手老夫妻）
  2. 校園黑板木質框（學士帽、彩色筆記）
  3. 藍天海洋向日葵框（草帽、紙船）
- **4x6 吋高畫質合成**：1800 x 1200 px（3:2 橫式），符合實體照片標準尺寸。
- **QR Code 手機下載**：自動上傳至免費雲端圖床（ImgBB），現場長輩/家屬拿手機掃碼即可秒存照片。
- **iPad 本地自動備份**：每張合成相片在 iPad 本地皆有一份備份。

## 🛠️ 技術棧
- 純前端架構（HTML5 + Tailwind CSS + Vanilla JS）
- HTML5 Canvas 圖片像素級合成
- QRCode.js 離線向量條碼產生
- 支援部署至 GitHub Pages（完全免費、免自架伺服器）

## 🚀 快速開始
1. 直接用瀏覽器開啟 `index.html`。
2. 允許瀏覽器使用相機權限即可開始體驗！
